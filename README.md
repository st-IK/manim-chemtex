# Manim ChemTex

A lightweight Python library for rendering and animating chemical
structures and reaction schemes in Manim.

[日本語](#日本語) | [English](#english)

---

## 日本語

### 概要

**Manim ChemTex** は，Manimから化学構造式・化学反応式を扱うための
軽量なPythonライブラリです．

LaTeXパッケージである `chemfig`，`mhchem`，`siunitx` を利用し，
化学構造式や反応式をManimのアニメーションオブジェクトとして
扱えるようにします．

特に，化学結合の個別操作や，反応矢印への試薬・反応条件の配置を
簡単に行えることを目的としています．

### 特徴

- `chemfig` による化学構造式の描画
- `mhchem` による化学式・化学反応式の記述
- `siunitx` による単位・数値表現
- 化学結合の太さの変更
- 化学結合の個別の色変更
- 化学反応矢印の作成
- 反応矢印の上下への試薬・反応条件の配置
- Manimのアニメーション機能との統合

### 基本的な使い方
```python
from manim import *
from manim_chemtex import ChemTex, ChemArrow


class Caffeine(Scene):
    def construct(self):

        caffeine = ChemTex(
            r"\\chemfig{N*5(-C(=O)-N(-CH_3)-C(=O)-N(-CH_3)-C(-H)=)}",
            font_size=40,
        )

        caffeine.set_bond_stroke(width=2)
        caffeine.set_bond_color(0, RED)
        caffeine.set_bond_color(1, BLUE)

        self.play(Write(caffeine))
        self.wait(2)
```
### 反応式
```python
reactant = ChemTex(
    r"\\chemfig{...}",
    font_size=30,
)

arrow = ChemArrow(
    [0, 0, 0],
    [4, 0, 0],
)

condition = arrow.above_obj(
    r"\\ce{H2SO4}",
)

temperature = arrow.below_obj(
    r"\\SI{80}{\\celsius}",
)
```

## English

### Overview

Manim ChemTex is a lightweight Python library for working with
chemical structures and chemical reaction schemes in Manim.

It uses the LaTeX packages `chemfig`, `mhchem`, and `siunitx`
to integrate chemical notation with Manim's animation system.

The main goal is to provide a simple interface for manipulating
chemical bonds and placing reagents and reaction conditions
around reaction arrows.

---
### Features
- Chemical structure rendering with `chemfig`
- Chemical formulas and reactions with `mhchem`
- Units and numerical expressions with `siunitx`
- Chemical bond width customization
- Individual chemical bond color customization
- Chemical reaction arrows
- Reagents and reaction conditions above/below arrows
- Integration with Manim's animation system

This project uses the following software and LaTeX packages:

- Python
- Manim
- LaTeX

- Limitations

Chemical bond detection currently relies on the vectorized
object structure generated by Manim.

Therefore, changes to Manim or the LaTeX/SVG rendering pipeline
may affect bond detection.
